# Equal-n Dataset A aggregation (\(k=37\))

Date: 31 August 2026.

Conversation length on Dataset A is highly variable. Eligible
condition windows (\(n=90\), 18 people \(\times\) 5 conditions) run
151.3–1007.7~s (median 382.9~s, mean 417.4~s). Complete 4~s epochs
run 37–251 (median 95, mean 103.8). A whole-condition median therefore
averages a different number of tiles for a short chat than for a long
one.

**Rule.** For each person \(\times\) condition, median the \(k\)
retained 4~s tiles whose midpoints are nearest the visual onset of
that condition’s advertisement. For \(a^{\emptyset}\), the same clock
is the matched turn-2 and turn-4 replies. \(k=37\) is the shortest
condition’s tile count, so every advertisement condition contributes
exactly 37 tiles and \(n=18\) is retained. Tiles remain
condition-start aligned; they are not recut at onset (that is
Dataset~B).

**Why 37.** It is \(\min_c \lfloor D_c/4\rfloor\) on the confirmatory
cohort, not a round number. Larger \(k\) cannot be offered to every
person without dropping short conversations.
