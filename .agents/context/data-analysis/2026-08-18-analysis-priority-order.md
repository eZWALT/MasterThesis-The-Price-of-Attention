# Analysis priority order (18 August 2026)

Walter's order of importance for the remaining data analysis.
Do not invert this in the paper, the thesis, or future analysis work.

1. **Behavioural battery by condition and presentation.**
   Trust, credibility, perceived manipulation, notice (and the rest of
   the post-condition instruments), for each of the five conditions and
   collapsed by format (implicit / explicit / \(a^{\emptyset}\)).
   Participant is the inferential unit. Notice and cued recall are a
   slice of this battery, not a substitute for trust.

2. **Interactions with personality and demographics.**
   Same outcomes × BFI-10 and demographics. BFI-10 is a moderator, not
   an input to \(a_k\).

3. **EEG.**
   Spectral, participant-level. No ERP claim. After the behavioural
   contrasts, not instead of them.

4. **Genre / attention / intent theory.**
   \(\delta^{(a)}_k\) only after early ads; late ads have no post-ad
   utterance. Association, not causal attention shift. Classifier must
   be frozen first.

5. **Multi-output insertion-policy model.**
   When it is a good moment to insert; feature importance. Last. The
   present sample is not a training corpus for \(\pi\).
