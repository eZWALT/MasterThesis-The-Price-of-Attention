## How to sell it without lying (the lock)

1. Results 7.5.1 leads with the **two-estimand** sentence: condition
   aggregation null, onset-lock trust × posterior \(\alpha\). Figure
   first, then only what the figure cannot say.
2. The specificity figure is the defence against "you looked at two
   bands": all sixteen, Holm-16, still one \(\alpha\) pair (plus its
   whole-scalp sibling). Write "one surviving pair", never "16
   measures, four hits".
3. Discussion 8.5 carries: weak nulls (Block 0 reliability, "no
   detectable", never "zero"); trust–\(\alpha\) at the onset not the
   state (same lesson as `sec:disc-eeg`); it is an \(\alpha\) result
   (indices silent, Fz \(\theta\) silent); one cell in 18 is a bounded
   hypothesis (carry the lower bound .48; point estimate inflated —
   reliabilities .56 × single-item trust cannot support .80 as a true
   value); process cluster is one exploratory pattern; trajectories do
   not join the triangle.
4. Do **not** write: the family after the heatmap (3×3 process ×
   index with Holm-9), "captured attention", "active processing",
   "allocation of neural processing", a serving rule, MDE / power, or
   "approached significance". Posterior \(\alpha\) is "the marker
   Methods declares for visual engagement" — that is the only
   mechanism vocabulary allowed.
5. `tab:results-summary` association rows get numbers; Sig. for

## Bug caught while doing this (do not repeat)

`combokit.spearman_ci` pairs its two inputs **by position**
(`np.asarray`). Passing two Series in different `experiment_id` orders
correlates row-for-row garbage. First run of the trajectory × EEG cell
gave \(\rho=.71\), Holm-2 .002, on misaligned rows; aligned it is .47,
Holm .095. `run_thesis_families.cell()` now aligns on the index before
calling it. Audit of the existing callers (`run_headline.py`,
`run_task_state.py`): every pair comes from one frame or from frames
built on `D.index`, so the documented Block 1 / Block 7 numbers stand.
